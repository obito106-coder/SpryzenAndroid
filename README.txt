Spryzen Android V1

Includes: Spryzen launcher app, futuristic chat UI, microphone voice commands, Android text-to-speech replies, and the Spryzen logo.

To build the APK on GitHub: upload this project to a GitHub repository, open Actions, select “Build Spryzen APK”, choose “Run workflow”, then download the “Spryzen-debug-apk” artifact.

Full cloud AI answers require connecting an AI provider/backend; no API key is included.
